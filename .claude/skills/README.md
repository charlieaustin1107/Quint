# Skills for Claude in this repo

Claude Code loads these automatically when a task matches their description. They make every session better at the things this project needs.

| Skill | What it's for | Source and licence |
|---|---|---|
| `quint-trading` | Researching, backtesting and teaching MNQ strategies; Quint's calls; Lucid limits; TradingView's call budget | Written for this repo |
| `quint-design` | The Neon HUD design system, phone rules, build, test and publish | Written for this repo |
| `quint-sound-haptics` | Sound effects (ZzFX), iPhone haptics, speaking and listening | Written for this repo |
| `web-3d` | 3D models, scenes and animated visuals that run well on a phone | Written for this repo |
| `frontend-design` | Distinctive, intentional page design | [anthropics/skills](https://github.com/anthropics/skills) at `e4bb5d9`, Apache-2.0 (`LICENSE.txt` inside) |
| `algorithmic-art` | Generative art, particles and flow fields with seeded randomness | [anthropics/skills](https://github.com/anthropics/skills) at `e4bb5d9`, Apache-2.0 (`LICENSE.txt` inside) |
| `webapp-testing` | Testing web pages with Playwright | [anthropics/skills](https://github.com/anthropics/skills) at `e4bb5d9`, Apache-2.0 (`LICENSE.txt` inside) |
| `web-haptics` | Haptic feedback patterns for web apps | [lochie/web-haptics](https://github.com/lochie/web-haptics) at `7904ed1`, MIT (`LICENSE` inside) |

The copied skills are unchanged from their sources. Where they suggest installing packages (for example `npm i web-haptics`), remember that Chart Wizard and Quint Brain are single self-contained pages: follow `quint-sound-haptics` and `web-3d` for how to bring that into this repo.
