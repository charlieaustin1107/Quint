# Where this folder came from

Every **Material Symbols** icon by Google, in one style: outlined, 24px.
Source: https://github.com/google/material-design-icons

- `outlined/` has the plain version of each icon and `filled/` the filled one. Both folders hold the same 4,157 names, e.g. `outlined/settings.svg` and `filled/settings.svg`.
- Copied from commit `10ecc14790612ca8fd164e3f4ffe9c16fc50d5b7` on 2026-11-18, from `symbols/web/<name>/materialsymbolsoutlined/`.
- The full repo (about 5 GB: every weight, size, grade, the rounded and sharp styles, PNGs, fonts) was left out on purpose. Any other variant can be fetched from the source when it's needed.
- Licence: Apache 2.0, see `LICENSE`. Copyright Google.
- Each icon is drawn in black by default. In a page, set `fill="currentColor"` (or CSS `fill`) to colour it for the black theme.
- No app uses these yet.
