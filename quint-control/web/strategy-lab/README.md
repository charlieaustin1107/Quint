# Strategy Lab UI prototype

Open index.html in a modern browser. It provides three local workflows:
- create an MNQ strategy draft from a structured description and optional safe JSON entry expression;
- record a one-off paper scenario with explicit entry, stop, target, trigger and expiry;
- review, export or delete saved local drafts.

Data is stored in browser localStorage. Export JSON to preserve it or move it into the future engine-backed website. This prototype is not connected to the NinjaTrader engine, market data, historical backtests, Playback, virtual fills, Claude or live accounts. It cannot place orders.

The full integration is planned after the Quint Control web shell and engine foundation (phases 1 and 2).
